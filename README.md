# TaskFlow — Smart Kanban Productivity Manager

TaskFlow is a lightweight Kanban-style task manager built with React, Vite, and Tailwind CSS. It provides a focused environment for organizing tasks into columns, tracking progress, and staying productive.

## Key Features
- Kanban board for organizing tasks into columns (To Do, In Progress, Done, etc.)
- Clean, responsive UI built with React + Tailwind CSS
- Fast dev experience powered by Vite
- Lightweight, extensible architecture ready for integrations or persistence layers
